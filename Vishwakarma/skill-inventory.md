# PM Skill Inventory — Self-Assessment

> Goal: produce an honest heatmap of strengths and gaps across the full PM craft, anchored to real evidence. Output of this exercise → top 3 gaps to focus on first.

## Rating scale

- **1** — Aware it exists, haven't really done it
- **2** — Done it once or twice with heavy guidance; output was rough
- **3** — Can do it independently for routine cases; quality is uneven
- **4** — Strong; peers come to me with these problems; can teach basics
- **5** — Recognized expert; can train others; notable wins came from it

**Rule:** Rating must be backed by one line of real evidence. No evidence → drop the rating by 1.

Known evidence base so far:
- **EMX**: built the intranet automatic AWB (Air Waybill) allocation system for a courier
- **Ceryne (CER)**: marketing, survey, and report work
